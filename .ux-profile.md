# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Notion
- **Notes:** "Fresh market": bright, photo-led and quick to scan, Zomato-style but premium. Pure white pages, a single rounded geometric sans (Figtree, closest free match to Zomato's proprietary face) for all text, light theme as the default in every interface, a strict 4px alignment grid, calm spacing, rounded cards on hairlines. Soft gold is the single accent (dark ink on gold fills, brand-ink for gold text and outlines) and status colours are soft. All six stalls share identical styling and are identified by name and photography, never by colour. Kitchen, waiter and admin dashboards are light too and may be denser inside the same grammar; night is an optional dark mode. Tokens, components and rules live in the DOSTANA DRIVE IN design system artifact (https://claude.ai/artifact/1B21oLLSbiM8qDCxhU6GbQ).

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary (remove the `.glass*` classes and the blurred bottom nav)
- Floating pastel pill badges for ordinary metadata (pills are only for order status and stall names, always with icon and word)
- Arbitrary decorative gradients and neon glowing borders, including gradient text, animated gradient borders and `rave-glow`
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Text 4.5:1, large text and meaningful borders, icons and focus rings 3:1, in both the Ivory and Night themes. Status is never colour alone: always icon plus word.
- **Touch / focus:** 44px minimum targets on the customer site, 52px in kitchen and waiter dashboards. Solid 3px focus ring offset 2px. Respect `prefers-reduced-motion`.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** A gracious host: "Your table is ready to order." Buttons name the result ("Place order", "Pay cash at table"). Stall names are always written in capitals (NANI'S TIFFINS, AROMA BIRYANI, DILLI'S D'LITE, TEA TIME, TALKS & TONIC, DOSTANA COOL POINT). Prices are whole rupees such as ₹60. Dine-in only: no delivery, address, rider or map language. Order states are Received, Preparing, Ready, Served.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (found in package.json)
- **Notes:** One icon set. 2px stroke, 18px inline and 24px in buttons. Replace the emoji currently used for categories and stalls in `src/data/menu.ts` with Lucide icons or photography.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
